# Design System Tokens - VisionFlow 2.0

Este documento mapeia os tokens visuais do projeto para garantir consistência em futuras iterações e no treinamento de IAs generativas (como o Stitch).

## Paleta de Cores

| Token | Valor Hex/RGBA | Uso |
| :--- | :--- | :--- |
| `--bg-color` | `#0f172a` | Fundo principal (Slate 900) |
| `--text-primary` | `#f8fafc` | Texto de títulos e corpo principal |
| `--text-secondary`| `#94a3b8` | Legendas, descrições e estados desativados |
| `--accent-color` | `#3b82f6` | Cor de destaque (Azul 500), cursor, botões primários |
| `--accent-hover` | `#2563eb` | Estado de hover para elementos de destaque |
| `--success-color` | `#10b981` | Feedback de sucesso e estado "Pinching" |
| `--error-color` | `#ef4444` | Alertas e erros |

## Glassmorphism (Efeito Vidro)

- **Fundo**: `rgba(30, 41, 59, 0.7)`
- **Borda**: `rgba(255, 255, 255, 0.1)`
- **Blur**: `12px` (Panels) / `16px` (Header)
- **Sombra**: `0 4px 30px rgba(0, 0, 0, 0.1)`

## Tipografia

- **Família**: `'Inter', sans-serif`
- **Tamanhos**:
    - Título Modal: `1.8rem` (700 weight)
    - Logo: `1.5rem` (700 weight)
    - Botões: `1rem` (600 weight)
    - Logs: `0.85rem`

## Raios de Borda (Corner Radius)

- **Painéis principais**: `16px`
- **Cards e Containers**: `12px`
- **Botões**: `8px`
