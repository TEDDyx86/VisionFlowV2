Como usar o Totem?

Nossa interface funciona sem toques físicos. Apenas use sua mão para controlar o sistema!

1. Levante a mão

Posicione sua mão aberta em frente à câmera para que o cursor apareça na tela.

2. Navegue

Mova a mão para mover o cursor pela tela. Pare sobre um botão para selecioná-lo.

3. Feche os dedos

Para "clicar", faça um movimento de pinça encostando a ponta do polegar no indicador.
